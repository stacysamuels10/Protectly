  <action>
Create `src/app/api/webhooks/stripe/route.test.ts` testing the POST handler with all 4 Stripe event types plus the duplicate event idempotency path.

**Mock setup (all vi.mock calls at top, before imports):**

1. `vi.mock('@/env', () => ({ env: { STRIPE_WEBHOOK_SECRET: 'whsec_test' } }))` -- only needs STRIPE_WEBHOOK_SECRET

2. `vi.mock('@/lib/stripe', () => ({ stripe: { webhooks: { constructEvent: vi.fn() } }, mapStripeStatus: vi.fn((status: string) => status.toUpperCase()) }))` -- mock constructEvent to return fake event objects; mapStripeStatus converts status to uppercase (simplified)

3. `vi.mock('@/lib/prisma', () => ({ prisma: { processedWebhookEvent: { create: vi.fn() }, user: { update: vi.fn(), findFirst: vi.fn() } } }))` -- mock all Prisma methods used by the handler

**After mocks, import:**
- `import { POST } from './route'`
- `import { stripe } from '@/lib/stripe'`
- `import { prisma } from '@/lib/prisma'`
- `import { Prisma } from '@prisma/client'`

**Typed mock references:**
- `const mockConstructEvent = vi.mocked(stripe.webhooks.constructEvent)`
- `const mockProcessedWebhookEvent = vi.mocked(prisma.processedWebhookEvent)`
- `const mockUserUpdate = vi.mocked(prisma.user.update)`
- `const mockUserFindFirst = vi.mocked(prisma.user.findFirst)`

**Helper functions:**

1. `makeStripeEvent(type: string, data: Record<string, unknown>, id = 'evt_test_123')` returns `{ id, type, data: { object: data } }`

2. `makeStripeRequest(body = '{}', sig = 'valid-sig')` returns a mock NextRequest-like object: `{ text: async () => body, headers: { get: (n: string) => n === 'stripe-signature' ? sig : null } } as any`

**beforeEach:** `vi.clearAllMocks()`, default `mockProcessedWebhookEvent.create.mockResolvedValue({} as any)`, default `mockUserUpdate.mockResolvedValue({} as any)`

**Tests (5 total minimum):**

1. **"handles checkout.session.completed — updates user to PRO with subscription":**
   - mockConstructEvent returns event with type 'checkout.session.completed', data object has `{ metadata: { userId: 'user-1', tier: 'PRO' }, subscription: 'sub_123', customer: 'cus_123' }`
   - Call `POST(makeStripeRequest())`
   - Assert response.status 200, body `{ received: true }`
   - Assert `mockUserUpdate` called with `where: { id: 'user-1' }` and `data` containing `subscriptionTier: 'PRO'`, `subscriptionStatus: 'ACTIVE'`, `stripeSubscriptionId: 'sub_123'`, `stripeCustomerId: 'cus_123'`

2. **"handles customer.subscription.deleted — resets user to FREE/CANCELED":**
   - mockConstructEvent returns event with type 'customer.subscription.deleted', data: `{ metadata: { userId: 'user-1' }, status: 'canceled' }`
   - Assert `mockUserUpdate` called with `subscriptionTier: 'FREE'`, `subscriptionStatus: 'CANCELED'`, `stripeSubscriptionId: null`

3. **"handles invoice.payment_failed — sets user to PAST_DUE":**
   - mockConstructEvent returns event with type 'invoice.payment_failed', data: `{ subscription: 'sub_123' }`
   - `mockUserFindFirst.mockResolvedValue({ id: 'user-1' } as any)`
   - Assert `mockUserUpdate` called with `subscriptionStatus: 'PAST_DUE'`

4. **"returns 200 without processing when event is a duplicate (P2002)":**
   - Create a proper P2002 error: `new Prisma.PrismaClientKnownRequestError('Unique constraint failed', { code: 'P2002', clientVersion: '5.7.1' })`
   - `mockProcessedWebhookEvent.create.mockRejectedValueOnce(p2002)`
   - mockConstructEvent returns a checkout event
   - Assert response.status 200, `{ received: true }`
   - Assert `mockUserUpdate` NOT called (event was skipped)

5. **"returns 400 when stripe-signature header is missing":**
   - Call `POST(makeStripeRequest('{}', null as any))` -- no signature header
   - The request mock's `headers.get('stripe-signature')` returns null
   - Assert response.status 400

6. **"returns 400 when constructEvent throws (invalid signature)":**
   - `mockConstructEvent.mockImplementation(() => { throw new Error('Invalid signature') })`
   - Assert response.status 400

Create `src/app/api/allowlists/allowlists.test.ts` testing cross-user access on the `[id]/entries` GET, `[id]/entries` POST, and `[id]/entries/[entryId]` DELETE handlers.

**CRITICAL: The handlers return 404 (not 403) for cross-user access** -- this is by design to avoid leaking information about whether a resource exists. Assert 404.

**Mock setup (all vi.mock calls at top, before imports):**

1. `vi.mock('@/lib/session', () => ({ getCurrentUser: vi.fn() }))` -- control which user is "authenticated"

2. `vi.mock('@/lib/prisma', () => ({ prisma: { allowlist: { findFirst: vi.fn() }, allowlistEntry: { findMany: vi.fn(), count: vi.fn(), findFirst: vi.fn(), create: vi.fn(), delete: vi.fn() }, auditLog: { create: vi.fn() } } }))` -- mock all Prisma methods used across the 3 handlers

3. `vi.mock('@/lib/utils', () => ({ isValidEmail: vi.fn(() => true), TIER_LIMITS: { FREE: { allowlistEntries: 50 }, PRO: { allowlistEntries: 500 }, BUSINESS: { allowlistEntries: 5000 } } }))` -- utils needs to be mocked since it's imported by entries route

**After mocks, import:**
- `import { getCurrentUser } from '@/lib/session'`
- `import { prisma } from '@/lib/prisma'`

**Typed mock references:**
- `const mockGetCurrentUser = vi.mocked(getCurrentUser)`
- `const mockAllowlistFindFirst = vi.mocked(prisma.allowlist.findFirst)`

**beforeEach:**
- `vi.clearAllMocks()`
- Set authenticated user to user B: `mockGetCurrentUser.mockResolvedValue({ id: 'user-b', email: 'b@example.com', subscriptionTier: 'FREE' } as any)`
- Set allowlist ownership check to fail (user A's allowlist not accessible by user B): `mockAllowlistFindFirst.mockResolvedValue(null)`

**Helper:**
- Build a mock NextRequest with `nextUrl.searchParams`, `json()` method, `text()` method, `headers.get()` as needed

**Tests (3-4 total):**

1. **"GET /api/allowlists/[id]/entries returns 404 for cross-user access":**
   - Dynamically import GET: `const { GET } = await import('@/app/api/allowlists/[id]/entries/route')`
   - Create request with minimal searchParams (page=1, limit=25)
   - Call `GET(request, { params: Promise.resolve({ id: 'user-a-allowlist-id' }) })`
   - Assert `prisma.allowlist.findFirst` was called with `{ where: { id: 'user-a-allowlist-id', userId: 'user-b' } }` (userId from session)
   - Assert response.status === 404

2. **"POST /api/allowlists/[id]/entries returns 404 for cross-user access":**
   - Dynamically import POST: `const { POST } = await import('@/app/api/allowlists/[id]/entries/route')`

   - Call `POST(request, { params: Promise.resolve({ id: 'user-a-allowlist-id' }) })`

4. **"returns 401 when user is not authenticated":**

   - Call any handler (e.g. GET entries)
   - Assert response.status === 401
