    1. Add `import { env } from '@/env'` at the top (after existing imports)
    2. Remove the line: `const webhookSigningKey = process.env.CALENDLY_WEBHOOK_SIGNING_KEY`
    3. Remove the console.log line that logs `!!webhookSigningKey`
    4. Replace the entire conditional block:
       ```typescript
       // REMOVE THIS:
       if (webhookSigningKey) {
         if (!verifyWebhookSignature(rawBody, signatureHeader, webhookSigningKey)) {
           console.error('[Calendly Webhook] Invalid webhook signature')
           return NextResponse.json({ error: 'Invalid signature' }, { status: 401 })
         }
         if (!isTimestampValid(signatureHeader)) {
           console.error('[Calendly Webhook] Webhook timestamp outside tolerance')
           return NextResponse.json({ error: 'Invalid timestamp' }, { status: 401 })
         }
         console.log('[Calendly Webhook] Signature verified successfully')
       }
       ```

       WITH this (unconditional — no guard):
       ```typescript
       // REPLACE WITH:
       if (!verifyWebhookSignature(rawBody, signatureHeader, env.CALENDLY_WEBHOOK_SIGNING_KEY)) {
         console.error('[Calendly Webhook] Invalid webhook signature')
         return NextResponse.json({ error: 'Invalid signature' }, { status: 401 })
       }
       if (!isTimestampValid(signatureHeader)) {
         console.error('[Calendly Webhook] Webhook timestamp outside tolerance')
         return NextResponse.json({ error: 'Invalid timestamp' }, { status: 401 })
       }
       console.log('[Calendly Webhook] Signature verified successfully')
       ```

    This change is purely a security hardening — no functional change when the env var is present, but it removes the bypass path that skipped verification when the key was absent.

    Note: The signatureHeader type may be `string | null`. Check the verifyWebhookSignature function signature in src/lib/webhook.ts to confirm it accepts null. If not, add a null check: `if (!signatureHeader || !verifyWebhookSignature(...))` — but do NOT restore the `if (webhookSigningKey)` outer guard.
