    **Create** `src/components/dashboard/csv-import-button.tsx`:
    - 'use client' component
    - Props: `{ allowlistId: string, subscriptionTier: string }` — tier passed from server component
    - Imports: Papa from 'papaparse', Dialog components, Button, useToast, Upload icon from lucide-react, useRouter from next/navigation, TIER_LIMITS from @/lib/utils
    - State:
      - `importing: boolean` (overall import in progress)
      - `progress: { current: number, total: number } | null` (progress tracking per D-03)
      - `showUpgradeDialog: boolean` (tier gate dialog per D-06)
      - `importErrors: string[]` (invalid row details per D-02)
    - Hidden file input: `<input ref={fileInputRef} type="file" accept=".csv" className="hidden" onChange={handleFileChange} />`

    **handleImportClick:**
    1. Check `TIER_LIMITS[subscriptionTier as keyof typeof TIER_LIMITS].csvImport`
    2. If false: set showUpgradeDialog=true, return (per D-06)
    3. If true: `fileInputRef.current?.click()` (per D-01, native file picker, no drag-and-drop)

    **handleFileChange(e):**
    1. Get file from e.target.files[0], return if none
    2. Set importing=true, importErrors=[]
    3. Parse with Papa.parse(file, { header: true, skipEmptyLines: true, complete: handleParseComplete, error: handleParseError })

    **handleParseComplete(results):**
    1. Find email column: case-insensitive match for 'email' or 'email_address' in Object.keys(results.data[0])
    2. If no email column found: show error toast "CSV must have an 'email' column", set importing=false, return
    3. Extract emails: results.data.map(row => row[emailColumn]?.trim()).filter(Boolean)
    4. If no emails: show error toast "No valid rows found", set importing=false, return
    5. Call processBatches(emails)

    **processBatches(emails: string[]):**
    1. Chunk into batches of 50 (BATCH_SIZE = 50)
    2. Track totals: totalAdded=0, totalDuplicates=0, allInvalid: string[]=[]
    3. For each batch:
       - Set progress = { current: batchIndex * 50, total: emails.length }
       - POST to `/api/allowlists/${allowlistId}/entries` with { emails: batch }
       - If response.status === 403: show toast "Allowlist limit reached", break loop
       - Parse response JSON, accumulate added/duplicates/invalid counts
    4. Set progress = { current: emails.length, total: emails.length }
    5. Show summary toast per D-02: "Added {totalAdded}, skipped {totalDuplicates} duplicates, {allInvalid.length} invalid"
    6. If allInvalid.length > 0: set importErrors to allInvalid (show inline list)
    7. Reset: importing=false, progress=null, fileInputRef.current.value = '' (prevents pitfall 3: file input not resetting)
    8. router.refresh() to reload allowlist data

    **chunk utility** (inline, no lodash):
    ```typescript
    function chunk<T>(arr: T[], size: number): T[][] {
      const chunks: T[][] = []
      for (let i = 0; i < arr.length; i += size) {
        chunks.push(arr.slice(i, i + size))
      }
      return chunks
    }
    ```

    **Render JSX:**
    ```
    <>
      <input ref={fileInputRef} type="file" accept=".csv" className="hidden" onChange={handleFileChange} />
      <Button variant="outline" disabled={importing} onClick={handleImportClick}>
        <Upload className="mr-2 h-4 w-4" />
        {importing ? `Importing... ${progress ? `${progress.current}/${progress.total}` : ''}` : 'Import CSV'}
      </Button>

      {/* Inline error list for invalid emails per D-02 */}
      {importErrors.length > 0 && (
        <div className="text-sm text-destructive mt-2">
          <p className="font-medium">Invalid emails:</p>
          <ul className="list-disc list-inside">
            {importErrors.slice(0, 10).map((email, i) => <li key={i}>{email}</li>)}
            {importErrors.length > 10 && <li>...and {importErrors.length - 10} more</li>}
          </ul>
        </div>
      )}

      {/* Upgrade dialog for Free users per D-06 */}
      <Dialog open={showUpgradeDialog} onOpenChange={setShowUpgradeDialog}>
        <DialogContent>
          <DialogHeader>
            <DialogTitle>CSV Import is a Pro Feature</DialogTitle>
            <DialogDescription>
              Upgrade to Pro to import emails in bulk from a CSV file.
            </DialogDescription>
          </DialogHeader>
          <div className="flex justify-end gap-2 pt-4">
            <Button variant="outline" onClick={() => setShowUpgradeDialog(false)}>Cancel</Button>
            <Button asChild>
              <a href="/dashboard/settings">Upgrade to Pro</a>
            </Button>
          </div>
        </DialogContent>
      </Dialog>
    </>
    ```
