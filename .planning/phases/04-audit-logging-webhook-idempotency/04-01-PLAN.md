**File 1: src/app/api/allowlists/[id]/entries/route.ts (POST handler)**

In the POST handler's email processing loop, add a `prisma.auditLog.create` call BEFORE the existing `prisma.allowlistEntry.create` call. This is the write-audit-first pattern — the audit record persists even if the entry creation fails.

Inside the `for (const email of emails)` loop, after the duplicate check passes and before `prisma.allowlistEntry.create`, insert:

```typescript
// Write audit record FIRST (persists even if entry creation fails)
await prisma.auditLog.create({
  data: {
    userId: user.id,
    action: 'ADD',
    targetEmail: normalizedEmail,
    allowlistId: id,
  },
})
```

The audit record is created only for emails that pass validation and are not duplicates (i.e., emails that will actually be added). Invalid and duplicate emails are skipped — no audit record for those.

**File 2: src/app/api/allowlists/[id]/entries/[entryId]/route.ts (DELETE handler)**

In the DELETE handler, BEFORE the existing `prisma.allowlistEntry.deleteMany` call, fetch the entry to get its email, then create the audit record.

After the allowlist ownership check succeeds and before `prisma.allowlistEntry.deleteMany`, add:

```typescript
// Fetch the entry to capture its email for the audit log
const entry = await prisma.allowlistEntry.findFirst({
  where: {
    id: entryId,
    allowlistId: id,
  },
})

if (!entry) {
  return NextResponse.json({ error: 'Entry not found' }, { status: 404 })
}

// Write audit record FIRST (persists even if deletion fails)
await prisma.auditLog.create({
  data: {
    userId: user.id,
    action: 'REMOVE',
    targetEmail: entry.email,
    allowlistId: id,
  },
})
```

Then change the existing `prisma.allowlistEntry.deleteMany` to `prisma.allowlistEntry.delete` using the entry's id since we already confirmed it exists:

```typescript
await prisma.allowlistEntry.delete({
  where: { id: entryId },
})
```

This is cleaner because we already verified the entry exists above.

No new imports needed — `prisma` is already imported in both files.
