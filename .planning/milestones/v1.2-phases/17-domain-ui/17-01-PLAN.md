    4.     5. Input field: `<div className="grid gap-4 py-4"><div className="grid gap-2"><Label htmlFor="domain">Domain *</Label><Input id="domain" type="text" placeholder="@company.com" value={domain} onChange={(e) => setDomain(e.target.value)} disabled={loading} required /></div></div>`
    6. `<DialogFooter>` — Discard button: `<Button type="button" variant="outline" onClick={() => setOpen(false)} disabled={loading}>Discard</Button>`, Submit button: `<Button type="submit" disabled={loading}>{loading && <Loader2 className="mr-2 h-4 w-4 animate-spin" />}{loading ? 'Adding...' : 'Add Domain'}</Button>`

    **handleSubmit logic:**
    1. `e.preventDefault()`, setLoading(true)
    2. `fetch(\`/api/allowlists/${allowlistId}/domains\`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ domains: [domain.trim()] }) })`
    3. `const data = await response.json()`
    4. If `!response.ok` → `throw new Error(data.error || 'Failed to add domain')`
    5. If `data.duplicates?.length > 0` → toast({ title: 'Domain already exists', description: `@${domain.trim().replace(/^@/, '')} is already on your allowlist.`, variant: 'destructive' })
    6. If `data.invalid?.length > 0` → toast({ title: 'Invalid domain', description: `@${domain.trim().replace(/^@/, '')} is not a valid domain. Use format: @company.com`, variant: 'destructive' })
    7. If `data.added > 0` → toast({ title: 'Domain added', description: `@${data.addedDomains[0]} has been added to your allowlist.`, variant: 'success' }), setOpen(false), setDomain(''), router.refresh()
    8. catch → toast({ title: 'Error', description: error.message, variant: 'destructive' })
    9. finally → setLoading(false)

    Input clears ONLY on successful add. Dialog stays open on error/duplicate/invalid.
